# silent-hill-html-game
Juego educativo para aprender HTML con temática Silent Hill

# 🌫️ Silent Hill: Aprendiendo HTML

Un juego educativo interactivo para aprender HTML mientras exploras un misterio inspirado en Silent Hill. Diseñado especialmente para adolescentes y con opciones de accesibilidad.

## 🎮 Características

- **5 niveles educativos** + 1 misión extra sobre HTML
- **Sonidos inmersivos** con Web Audio API
- **Sistema de puntuación** persistente (localStorage)
- **Progreso guardado** en cookies
- **Modos de accesibilidad** inclusivos:
  - 🌿 Modo Serenidad
  - 🌙 Modo Descanso
- **Manual de ayuda** integrado
- **Responsive** para todos los dispositivos

## 📚 Contenido Educativo

1. Estructura básica de HTML (body)
2. Enlaces y atributos (href)
3. Imágenes (src)
4. Listas (ul)
5. Formularios (type)
6. HTML semántico (header)

## 🚀 Cómo jugar

1. Lee la historia y la pista
2. Escribe tu respuesta en el campo de texto
3. Presiona "Enviar" o la tecla "Enter"
4. Si aciertas, avanzas al siguiente nivel
5. ¡Completa los 6 niveles para ganar!

## ♿ Accesibilidad

- **🌿 Modo Serenidad**: Reduce colores brillantes y sonidos fuertes
- **🌙 Modo Descanso**: Elimina animaciones y parpadeos
